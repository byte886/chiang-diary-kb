# 《蒋中正日记》1917–1972：官方原始图像 PDF 与转稿采集方案

**版本：v2.0**
**日期：2026-09-29**
**用途：直接交给桌面版 AI IDE 执行**

---

# 0. 项目目标

本项目的目标非常明确：

> 尽可能完整地获取《蒋中正日记》的官方原始数字影像，并为每一个档案件建立对应的 PDF 和转稿文本。

**不建立数据库。**

**不建立本地全文检索系统。**

**不做 RAG。**

**不做向量数据库。**

**不做复杂 Web UI。**

最终得到一个结构清晰的本地资料库：

```text
《蒋中正日记》
│
├── 原始图像 PDF
│
└── 对应转稿
```

并且任何一个 PDF 都必须能够追溯：

```text
年份
日期
典藏号
国史馆原始页面
```

# 6. 为什么使用典藏号作为目录名

例如：

```text
002-150101-00037-141
```

这个编号比日期可靠。

因为一个日期可能存在：

* 多个档案件
* 附件
* 剪报
* 杂录
* 多个数字文件

因此目录应该使用：

```text
catalog_no
```

而不是：

```text
1947-04-09
```

# 9. 转稿来源优先级

转稿不一定全部自己 OCR。

按照以下优先级寻找：

```text
1. 官方已有转稿
        ↓
2. 正式出版物转稿
        ↓
3. 已有可靠公开转稿
        ↓
4. GitHub 等公开文本
        ↓
5. 自己 OCR
```

但是：

**无论转稿来自哪里，原始图像 PDF 都应该尽量来自官方档案。**

# 11. OCR

如果没有现成可靠转稿：

```text
官方原始图像
        ↓
PaddleOCR
        ↓
Markdown / TXT
```

建议优先保存：

```text
.md
```

而不是只保存 TXT。

因为以后可以加入：

* 页码
* OCR 标记
* 校正说明
* 不确定字符
* 原图对应关系

---

# 12. 转稿格式

推荐：

```markdown
# 蒋中正日记

日期：1947-04-09

典藏号：002-150101-00037-141

---

## Page 1

OCR / 转稿内容……

---

## Page 2

OCR / 转稿内容……

---
```

这样：

```text
PDF Page 1
    ↕
Markdown Page 1

PDF Page 2
    ↕
Markdown Page 2
```

尽量保持一一对应。

---

# 13. OCR 必须保留页码

例如：

```markdown
## Page 001

……

## Page 002

……

## Page 003

……
```

不要把整份 OCR 合并成没有页码的一大段文字。

因为以后发现 OCR 错误时，需要能够：

```text
文字
 ↓
Page 023
 ↓
PDF 第 23 页
 ↓
原始手稿
```

---

# 14. OCR 原文不要过度自动修改

OCR 输出：

```text
raw transcription
```

原则上不要自动“润色”。

例如 OCR 识别：

```text
蔣
```

不要擅自变成：

```text
蒋
```

也不要擅自：

* 改写句子
* 补全内容
* 修改日期
* 修改人名
* 修改地名

除非有明确的可靠转稿作为依据。

# 16. PDF 的生成原则

如果国史馆直接提供 PDF：

> 优先保存官方 PDF。

如果官方只提供图片：

```text
官方 JPG / PNG / TIFF
        ↓
按照原始顺序
        ↓
合并成 PDF
```

这个 PDF 的目标是：

> **忠实保存官方数字影像。**

不要：

* 压缩过度
* 降低分辨率
* OCR 覆盖原图
* 添加水印
* 修改图像内容

---

# 17. 如果只能获得 JPEG

例如：

```text
001.jpg
002.jpg
003.jpg
```

生成：

```text
002-150101-00037-141.pdf
```

PDF：

```text
Page 1 = 001.jpg
Page 2 = 002.jpg
Page 3 = 003.jpg
```

顺序必须与官方数字文件顺序一致。

# 28. HTML 错误页面检测

不能因为：

```text
HTTP 200
```

就认为下载成功。

必须检查：

```text
Content-Type
文件大小
Magic Bytes
实际图片解码
```

例如 JPEG：

```text
FF D8 FF
```

如果下载下来的是：

```html
<html>
...
```

则判定下载失败。

# 42. 最终项目原则

```text
官方原始影像优先
        ↓
每件一个 PDF
        ↓
每件一个对应转稿
        ↓
典藏号作为核心标识
        ↓
原图不修改
        ↓
OCR 不覆盖原图
        ↓
转稿保留来源
        ↓
PDF 保存 SHA-256
        ↓
支持断点续传
        ↓
支持未来增量
```

**不要建设数据库。**

**不要建设全文检索。**

**不要建设 RAG。**

**不要为了“工程完整”增加与最终目标无关的系统。**

项目只专注于两件核心成果：

1. **尽可能完整的官方原始图像 PDF**
2. **尽可能完整、且与原始图像对应的转稿**
